# Infra Canvas v0.1.1

v0.1.0 の機能を引き継ぎ、リリースと Docker 配布の検証・復旧手順を整えた更新です。既存 DSL の移行は不要です。

## 主な変更

- タグ作成から GHCR 配布、配布イメージの検証、日本語 GitHub Release 公開までを一つの手動実行パイプラインにまとめました。
- main の対象 SHA で通常 CI・Docker CI が成功し、版と日本語ノートが一致することを確認してから配布します。
- arm64・amd64 の両方で匿名 pull と起動・ブラウザー操作を検証し、成功後に安定版の `latest` と GitHub Release を更新します。
- 同じ SHA のタグと配布済み digest を再利用し、途中失敗からの再実行に対応しました。版・SHA・digest の衝突は上書きせず停止し、古い版への `latest` の巻き戻しを防ぎます。
- README に公開済みの Release・GHCR へのリンクとバージョン固定の起動方法を追加し、リリース用 PR・実行・復旧の運用手順を整備しました。

## 引き続き利用できる機能

独自 DSL・Terraform からの構成図生成、構成図の探索と属性編集、DSL の保存・読み込み、SVG・PNG 出力、印刷、単一 HTML のオフライン利用に対応しています。
