# ライセンスの選択

2026年10月16日、将来の商用化と OSS 提供を両立する方針として、管理者の判断で MIT を採用しました。
対象は本体のコード・文書・独自素材です。第三者素材の例外は [利用条件一覧](../THIRD_PARTY_NOTICES.md) を参照してください。

## 商用化との関係

[MIT の原文](https://opensource.org/license/mit) は利用・改変・再配布・販売・再許諾を認めています。
そのため有料 SaaS、商用サポート、将来の独自機能の有料提供と併用できます。
一方、第三者による商用利用・競合サービスの運営・改変版の非公開配布も許容する選択です。
著作権・許諾表示の維持が必要です。[GitHub の解説](https://choosealicense.com/licenses/mit/) も参照してください。

MIT は収益や競合排除を保証しません。将来別の提供条件を設けても、既に MIT で配布した版を
受領した利用者の許諾を後から取り消せる前提にしないでください。
外部から貢献を受け入れる際は、投稿者に権利があり MIT で提供されることを確認します。
第三者コードを将来別条件で提供する場合は、そのコードの権利と許諾を別途確認します。

## 配布上の注意

本体の MIT は、クラウドやサービスのロゴ・商標・第三者依存を一括して MIT にするものではありません。
公開リポジトリと配布物に本体の LICENSE と第三者の必要な表示を保持してください。
今の `package.json` の `private: true` は npm への誤公開を防ぐ設定として維持します。
GitHub の public/private や商用利用の可否を決める設定ではありません。
